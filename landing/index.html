INSTALL

홈 화면에 추가하기

  1. 휴대폰에서 앱 열기

    안드로이드는 Chrome, 아이폰은 Safari로 아래 ‘앱 열기’를 누릅니다.

  2. 홈 화면에 추가

    Chrome은 오른쪽 위 ⋮ → 홈 화면에 추가, Safari는 공유 버튼 → 홈 화면에 추가를 누릅니다.

  3. 성경 파일 가져오기

    가지고 계신 성경 데이터(.bdb) 파일을 설정 → 성경 파일 가져오기로 한 번만 넣으면 됩니다. 본문은 기기 안에만 저장됩니다.
